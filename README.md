A 1024x1024 newspaper-style image summing up the world news of Tuesday 17 November 2026: bridges under fire in the Russia-Ukraine war, Iran and the Strait of Hormuz, the Xi-Trump-Putin meeting, AI chip curbs, and Israel's Knesset. The image is drawn with Pillow by tools/generate_image.py from the day's reported stories; main.ts copies entry.png to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

To redraw the image first: `python3 tools/generate_image.py`
